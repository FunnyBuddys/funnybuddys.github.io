# funnybuddys.github.io

Kleine Seite zum Android-Spiel Nonsensor und die `app-ads.txt` für AdMob.

- `index.html`: die Seite (Deutsch und Englisch, ohne Cookies, ohne fremde Server)
- `app-ads.txt`: Verkäufer-Angabe für Anzeigen in der App (Google AdMob)
